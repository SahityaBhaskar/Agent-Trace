Local Engineering Architecture

Why AgentTrace Runs on Your Machine

While this marketing website is hosted on Vercel so anyone can explore the concept and interactive demo, the real AgentTrace engine runs on your local machine or internal CI runners. Here's why this architecture is essential:

lock
Zero Proprietary Code Exfiltration

Your Git tree, uncommitted diffs, and private repositories remain strictly on your local disk.

cable
Direct Socket & File Transcript Watching

AgentTrace watches Claude Code (~/.claude/projects/) and Cursor in real-time as they emit events.

speed
Sub-Second Native AST Analysis

Fast AST traversal over local files generates full transitive call graphs without network roundtrips.

Ready to take control of your AI agents?

Get started in under 90 seconds. No API key required to run with the pre-baked test scenarios.

Quick Install (Python 3.10+) 
# 1. Clone repository
git clone https://github.com/SahityaBhaskar/Agent-Trace.git
cd agent-trace && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. Launch the pre-baked Payment Retry report & control plane
python -m agent_trace.cli report --scenario payment --serve

# 3. Analyze your own live repo
python -m agent_trace.cli analyze /path/to/repo --serve
