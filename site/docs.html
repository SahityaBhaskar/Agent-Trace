Local Engineering Guide

Setting Up AgentTrace Locally

This guide covers how to install AgentTrace, hook it into your active AI coding agent sessions (Bob 2.0, Claude Code, Cursor), and launch your private developer control plane.

security

Why AgentTrace Runs Locally on Your Machine

While this website is hosted on Vercel so teams can explore documentation and test pre-baked scenarios, AgentTrace is intentionally designed as a local-first developer tool:

  • Zero Source Code Transmission: Your private git tree, uncommitted diffs, and ASTs are parsed on your workstation. No proprietary code is sent to third-party cloud storage.
  • Direct Session Discovery: AgentTrace monitors active local transcript directories (such as Claude Code's ~/.claude/projects/) without requiring manual exports.
  • Sub-Second AST Parsing: Transitive call graphs and symbol impact are calculated natively with zero network overhead.

01. 90-Second Quickstart

No API keys are required to test with pre-baked scenarios. Run these commands in your terminal:

bash
# 1. Clone repository & install dependencies
$ git clone https://github.com/SahityaBhaskar/Agent-Trace.git
$ cd agent-trace && python -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
# 2. Launch the pre-baked Payment Retry scenario report & web server
$ python -m agent_trace.cli report --scenario payment --serve
✓ Control Plane serving at http://127.0.0.1:8000
→ Open your browser to explore Causal Graph, Blast Radius, & Learning Hub

03. Connecting With AI Agents

smart_toy

Claude Code Integration

Claude Code writes session transcripts to ~/.claude/projects/. AgentTrace automatically discovers and streams these sessions.

$ agent-trace daemon --watch ~/.claude/projects/
code

Cursor & Live Git Tree

AgentTrace inspects real-time working tree changes made by Cursor or any agent. It parses git diffs directly against AST symbol tables.

$ agent-trace analyze /path/to/repo --diff auto --serve

04. Dual-Brain Engine Configuration

AgentTrace uses a dual-brain architecture to balance instant response times with deep architectural synthesis:

bolt
System 1 (Jev TypeSafe Heuristic Engine)

Runs locally in ~400ms. Classifies change types, computes blast radius scores, and flags breaking risks deterministically without external LLM API calls.

psychology
System 2 (Gemini Deep Reasoning Engine)

Enabled when GEMINI_API_KEY is set. Powers the 5-tier architectural flow synthesis and answers "Ask Why" grounded queries.

Environment Setup (.env)
# Optional: Enable deep reasoning synthesis
export GEMINI_API_KEY="AIzaSy..."
# Optional: Control Plane server port (default: 8000)
export PORT=8000

05. CLI Commands Reference

Command Options Description
agent-trace report --scenario [payment|auth] --serve Prints scenario report in terminal and opens web control plane.
agent-trace analyze <path> --diff [auto|staged|HEAD~1] --serve Analyzes live repository AST and git changes with impact graph.
agent-trace daemon --watch <path> --port <port> Runs background watcher for Claude Code or agent transcripts.

06. Frequently Asked Questions

Does AgentTrace require sending my codebase to third-party clouds?

No. AgentTrace is designed to run 100% on your workstation or internal CI server. Your repository code, file contents, and commit history never leave your machine.

Why is this marketing website hosted on Vercel if the tool runs locally?

The Vercel-hosted site provides a public presentation of what AgentTrace is, lets visitors test the interactive demo sandbox directly in the browser, and provides documentation for developers looking to install it locally.

Can I integrate AgentTrace into our GitHub Actions or GitLab CI pipeline?

Yes! You can run python -m agent_trace.cli analyze . --diff auto in CI as a PR gate to block breaking changes, calculate blast radius, and generate pull request comments.
